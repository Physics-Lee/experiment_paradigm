# Example Video Guidance

This directory contains the original English demonstration videos for the
sentence paradigm's preparation and playback combinations.

- Filenames encode the demonstrated modes (`dots` or `square`, and `green` or
  `progress`); keep that naming relationship intact.
- Treat the MP4 files as intentional, versioned reference assets. Do not
  regenerate, recompress, rename, or delete them without explicit approval.
- These videos are documentation examples, not runtime inputs to the Python
  entry points.
