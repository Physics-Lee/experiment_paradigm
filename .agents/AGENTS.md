# `.agents` Guidance

This directory is reserved for project-owned agent configuration or reusable
automation guidance.

- Keep instructions repository-specific and consistent with the root
  `AGENTS.md`.
- Do not place generated transcripts, scratch prompts, credentials, or
  machine-specific state here.
- If a new agent configuration references scripts or documents, use paths
  relative to the repository root and update those references when files move.
