# 手势图片（gestures）

本目录存放与 `stimuli.txt` 中每个数字配对的手势图片（第 i 行刺激 ↔ 第 i 张）。当前
`01.jpeg`～`10.jpeg` 是**真实手势照片**。

## 命名与格式

- 编号：`01`～`10`（两位数字，第 i 行刺激 ↔ 第 i 张）。
- 格式：`.jpg` / `.jpeg` / `.png` 均可（大小写不限）。同一编号若同时存在多种格式，
  优先级为 jpg/jpeg > png（真实照片优先于生成图）。

| 编号 | 数字 | 建议手势（中国单手数字手势） |
| --- | --- | --- |
| 01 | 一 | 伸 1 指 |
| 02 | 二 | 伸 2 指 |
| 03 | 三 | 伸 3 指 |
| 04 | 四 | 伸 4 指 |
| 05 | 五 | 张开手掌 |
| 06 | 六 | 拇指 + 小指（🤙） |
| 07 | 七 | 拇指 + 食指 + 中指捏拢 |
| 08 | 八 | 拇指 + 食指张开成 L（枪） |
| 09 | 九 | 食指弯钩 |
| 10 | 十 | 握拳 |

## 替换图片

把照片按 `01`～`10` 编号直接覆盖即可（`.jpg`/`.jpeg`/`.png` 任选），**无需改动任何代码**。
建议接近正方形、分辨率不低于 600×600。如需重新生成矢量示意图（会覆盖为 `.png`）：

```
python make_gestures.py
```

## 运行时容错

若某个编号的图片缺失，范式会在屏幕右侧即时绘制一张带编号的占位卡片，不会崩溃，并会在
结果文件里把该 trial 标记为 `gesture_placeholder=true`。
