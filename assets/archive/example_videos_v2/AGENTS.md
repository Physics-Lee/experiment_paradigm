# Version 2 Example Video Guidance

This directory contains versioned demonstrations of the listening, speaking,
and reading paradigms.

- Preserve the task-to-filename mapping when replacing or adding examples.
- Treat the MP4 files as intentional, versioned reference assets. Avoid
  recompression or metadata-only rewrites that create large binary diffs.
- These videos are documentation examples and are not loaded by the Python
  scripts at runtime.
