# 闭锁患者句子朗读范式

当前维护的命令默认使用 `stimuli/yan_jiangyi_v4.txt`，以及
`assets/sentence_audio/yan_jiangyi_v4_slow/manifest.json`。

## 单试次流程

```text
实验开始前静息基线：1.5～2.5秒（仅第一个 trial）
→ 白色文字和红色正方形出现
→ 音频前延迟：0.4～0.6秒，随机
→ 播放目标句音频，文字和红色正方形保持显示
→ 静默延迟：1.5～2.0秒，随机
→ 下半屏方块由红变绿：整句开始
→ 第一字的进度条同时开始
→ 后续汉字的进度条依次填充，默认3.0秒/字
→ 最后一个字完成后保持0.5秒
→ 休息：5～6秒，默认显示中央灰色十字；可选改为纯黑屏
→ 直接进入下一 trial 的白色文字/红色正方形画面
```

方块变绿和第一个汉字的进度条开始应当同时发生，使整句 onset
与第一个字 onset 没有歧义。方块随后保持绿色，直到最后一个汉字完成。
白色文字和红色正方形使用同一 onset；目标音频在该 onset 之后
随机延迟 0.4～0.6 秒开始。
多字纯中文刺激默认逐字送入 TTS，运行时按顺序连续播放每个字的音频片段。

考虑患者视力问题，可以让统一“滴”声与方块变绿同步出现，作为冗余
提示。该提示音在五类需求中完全相同，不携带类别信息。
默认音量为 0.7，可使用 `--cue-volume` 在 (0, 1] 范围内调整。

休息画面默认是黑底中央灰色十字。传入 `--no-rest-cross` 后，休息时改为
纯黑屏。休息画面与前一 trial 的最终画面、后一 trial 的白字/红方块
画面直接切换，不额外插入过渡画面。

可用 `--repetitions N` 将完整刺激列表循环 N 次；每轮默认独立随机打乱顺序，
传入 `--no-shuffle` 可改为按刺激文件顺序呈现。结果中的 `stimulus_index` 保留刺激文件
原始行号，`repetition` 和 `repetition_trial` 记录轮次及轮内序号。

## 屏幕布局

```text
┌──────────────────────────────┐
│                              │
│        我  要  喝  水         │  上半屏50%
│        白字，背景条逐字填充     │
│                              │
├──────────────────────────────┤
│                              │
│          ███████             │
│          █ 红→绿 █            │  下半屏50%
│          ███████             │
│                              │
└──────────────────────────────┘
```

视觉规格：

- 使用黑色背景。
- 默认 `progress` 模式中汉字保持白色，与汉字同高的背景进度条
  依次填充。
- 汉字单行居中，自动缩放到上半屏可容纳的最大字号。
- 汉字高度约占上半屏的70%～80%。
- 方块边长约占下半屏高度的70%～80%。
- 方块在下半屏水平、垂直居中。
- 不使用小型进度条或小型注视点作为关键提示。
- 已完成汉字的背景进度条保留，使患者能够看到当前进度。
- 可选 `green` 模式中，汉字依次变绿并保持绿色。

## 需要记录的时间戳

每个试次至少记录：

- 目标音频 onset、offset；
- 多字刺激中每个字音频片段的 onset、offset；
- 文字/红色正方形 onset；
- 音频前延迟的计划值和实际值；
- 静默延迟的计划值和实际值；
- 方块变绿时间；
- 统一提示音时间；
- 每个汉字各自的进度开始与完成时间；
- 最后一个汉字完成时间；
- 试次结束时间。

## 实现注意事项

当前 [`main_en.py`](../main_en.py) 的句子范式按空格切分“单词”，正式
实现时必须改为按汉字呈现，同时加入自适应大字体、大方块、随机音频后
延迟和逐字时间戳。

原始 [`main.py`](../main.py) 已有逐字符逻辑，可以将这部分迁移到带音频
和时间戳的新版范式中。

新版保留旧实现的两种视觉模式：`--play-mode progress` 为默认的逐字
背景进度条，`--play-mode green` 为可选的累积逐字变绿。进度条速度和字间停顿
分别由 `--progress-duration` 和 `--progress-pause` 控制。
