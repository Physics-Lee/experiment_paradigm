# Reference Material Guidance

This directory contains local raw recordings and other source material used
only for comparison during development.

- Reference files are not runtime experiment inputs; versioned runtime media
  belongs under `assets/`.
- Large reference files are ignored by default. Do not move them into `assets/`
  unless they are deliberately selected as maintained project fixtures.
- Do not recompress, rename, or delete user-provided reference media without
  explicit approval.
