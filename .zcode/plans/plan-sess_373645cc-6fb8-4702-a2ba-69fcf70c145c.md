## 目标(缩小范围)

只给**闭锁患者范式** `run-sentence-audio-zh`(`LockedInSentenceReadingParadigm`)新增 `--font-size` 参数,作为**字号上限**:自适应布局仍在上限内尽量放大,长句自动缩小不溢出。

**不改** `base.py` / `sentence.py` / 其他范式——闭锁范式绘制用 `layout["font"]`(动态生成),不依赖基类 `self.font` / `self.font_size`,所以无需透传到父类。改动隔离在 2 个文件。

## 改动清单(2 个文件)

### 1. `src/experiment_paradigm/paradigms/locked_in_reading.py`

**(a)** `__init__` 签名(第 21-47 行)末尾加一个关键字参数:
```python
        display_mode="borderless",
        font_size=80,
    ):
```

**(b)** 校验区(第 65 行附近,其他校验旁边)加一条:
```python
        if font_size < 12:
            raise ValueError("font_size must be at least 12")
```
(下限 12 对齐 `_sentence_layout` 内部的 `minimum_size = 12` 和 `RelaxingNewsParadigm` 的既有惯例。)

**(c)** 存为属性(在 `self.shuffle = shuffle` 那块附近,第 118 行左右):
```python
        self.max_font_size = font_size
```

**(d)** `_sentence_layout` 第 180 行,把字号上限算式收紧:
```python
        # 原:
        maximum_size = max(minimum_size, maximum_height)
        # 改为:
        maximum_size = max(minimum_size, min(self.max_font_size, maximum_height))
```
效果:二分搜索仍向上找"能放下的最大字号",但不超过 `--font-size`。短句若放得下就显示 `max_font_size`;长句仍自动缩小。`min(..., maximum_height)` 保证不会超过屏幕高度约束,`max(minimum_size, ...)` 保证下限不破。

**无需改** `display_sentence` / `_draw_locked_in_state`——它们都从 `layout["font"]` / `layout["font_size"]` 取值,自动反映新上限。`trial_data["font_size"]` 已读 `layout["font_size"]`,记录的也是实际选中字号。

### 2. `src/experiment_paradigm/commands/locked_in_reading.py`

**(a)** 在 "视觉提示与速度" 参数组(`visual = parser.add_argument_group(...)`,第 94 行)里加参数,风格对齐同文件其他参数:
```python
    visual.add_argument(
        "--font-size",
        type=int,
        default=80,
        help="汉字字号上限;自适应仍会在该上限内尽量放大,长句自动缩小。",
    )
```
默认 `80` = 维持现行行为(不加参数时完全不变)。

**(b)** `main_locked_in()` 里构造 `LockedInSentenceReadingParadigm(...)` 的调用(第 222-247 行)末尾追加:
```python
        font_size=args.font_size,
```

## 不改动的内容
- `base.py` 的 `BaseParadigm`:不动(闭锁范式不用基类字体)。
- `sentence.py` 的 `SentenceParadigm`:不动(用户此次未要求)。
- `commands/sentence.py`:不动。
- `cli.py` / `scripts/run_sentence_audio_zh.py`:都是 re-export / 薄封装,参数自动透传,无需改。
- 现有测试:无任何测试对字号数值或 `_sentence_layout` 的 `maximum_size` 做断言(`test_sentence_audio.py` 只断言 `play_mode`/`text_y`/`square_*`),不破坏。
